# P1-6 · Reduce back-office startup work

risk: high · surface: ui,security · lane: shell

Defer the Statistics map, self-host the app fonts, scope the Statistics client messages, and skip session refresh on the integration webhook paths.

## Done when

- The per-wilaya table is available before the map code arrives. The map loads in a separate client chunk with both d3 modules, with reserved space during loading. Hover sync, keyboard selection, commune drill-down, the legend and RTL still work.
- The app serves IBM Plex Sans and IBM Plex Sans Arabic as same-origin font assets with the existing weights and fallbacks. EN, AR and mixed-script content keep their typography, and the public store keeps its separate font setup.
- The root app client payload omits the `statistics` namespace. Statistics and the all-orders list receive the messages their clients need. Server translations, direct loads, client navigation and error boundaries work in both locales.
- Only the `/api/webhooks` path segment is newly exempt from the proxy. The three providers still enforce their own signature checks, and session refresh still covers the app and login.

## Files

1. `src/components/stats/wilaya-section.tsx` — switch the named `AlgeriaMap` import to a module-level `next/dynamic` call in this Client Component, with a sized loading placeholder and client-only map rendering. Keep `WilayaMapDatum` type-only. `src/components/dashboard/algeria-map.tsx` owns geometry and stays the dynamic import target. The production caller is Statistics, despite the map's directory name.
2. `src/app/(app)/layout.tsx` and `src/app/(app)/globals.css` — add `IBM_Plex_Sans` (Latin, 400/500/600/700) and `IBM_Plex_Sans_Arabic` (Arabic, 400/500/600) via `next/font/google`, use their variables in the app font stack, and remove the external stylesheet. Use swap and check mixed-script rendering with the generated fallback stack.
3. `src/app/(app)/layout.tsx` — pass client messages without `statistics`. Keep the complete EN/AR catalogs and cookie handling in `src/i18n/request.ts` for server callers.
4. `src/i18n/statistics-messages-provider.tsx` (new, client) — add the supplied `statistics` messages to the parent `useMessages()` result and pass the merged object to a nested provider. `src/app/(app)/app/statistics/layout.tsx` and `src/app/(app)/app/sell/orders/(list)/layout.tsx` — keep `AdminGuardLayout` and pass the locale's namespace from `getMessages()` to the scoped provider. Cover `statistics/error.tsx` and `orders-filter-bar.tsx`; the Seasons page and order drill helper use server translations.
5. `src/proxy.ts` — add a segment-bounded `api/webhooks(?:/|$)` exclusion to the existing literal matcher. Leave `src/lib/supabase/session.ts` and the Shopify, Lightfunnels and ZR route handlers intact. `src/components/store/store-theme.test.ts` — extend the matcher coverage using Next's installed matcher test helper.
