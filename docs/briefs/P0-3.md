## Changes
1. `src/lib/integrations/zrexpress.ts`
   - `const PROD_BASE="https://api.zrexpress.app/api/v1"`; `zrBaseUrl()` = `process.env.ZR_API_BASE ?? PROD_BASE`, evaluated per call (tests can set env).
   - Refuse: if resolved base === PROD_BASE and `process.env.VERCEL_ENV !== "production"` (or NODE_ENV!=="production" when no VERCEL_ENV) and `ZR_ALLOW_PROD !== "1"`-no: NO escape hatch -> throw ZRExpressError("ZR prod API blocked outside production; set ZR_API_BASE"). Apply to every call (incl. reads) in `zrFetch`. Vitest has NODE_ENV=test => blocked unless ZR_API_BASE set.
   - Also reject non-https base unless host is localhost/127.0.0.1 (mock server).
   - Add `findZRParcelByExternalId(creds, externalId): Promise<{id,trackingNumber,state}|null>` via `/parcels/search` (pageSize 1).
2. `src/lib/integrations/zrexpress-push.ts`
   - Before `createZRParcel`: call `findZRParcelByExternalId`; if found, adopt that parcel (no second create). If lookup errors -> abort push (return error), never create blind.
   - On insert error: if code 23505 -> treat as already-sent ok:false "already sent" (message must contain "already sent"); else log + return error telling admin parcel `<id>` exists at ZR (retry will adopt via externalId).
3. `scripts/zr-probe.ts`: honour `ZR_API_BASE` (optional, 1 line).
4. New `src/lib/integrations/zrexpress-push.test.ts` + tiny `node:http` mock server (ephemeral port, sets `process.env.ZR_API_BASE`), fake supabase builder (chainable stub; not local DB).
