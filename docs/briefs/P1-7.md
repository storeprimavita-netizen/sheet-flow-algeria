# P1-7 brief — delivery prices from the owner's CSV (D27, D14, D38)
risk: high · surface: ui · lane: orders

Goal: an admin imports `prices/Algeria_numbered.csv`-format files (preview first), edits fees per wilaya in Settings → Delivery fees, and shipping availability + commune lists follow the data.

## Definition of done
- Pure parser `src/lib/delivery-prices.ts` (+ unit tests) turns CSV text into `{wilayas:[{code,name,home,stopdesk,communes[]}]}` plus warnings; no I/O.
- Settings → Delivery fees: "Upload CSV" opens a preview (per wilaya: old → new home/stop-desk, availability change, new/removed communes, warnings); nothing is written until "Apply"; one transactional apply.
- Wilaya without a price → `stop_shipping=true`; home-only → `stopdesk_available=false` (order form and, later, store hide stop-desk). Never treated as a 0 DZD fee.
- Commune list per wilaya stored from the same file and offered in the order form commune picker (free text stays allowed for old orders).
- COD pushed = sale·qty + fee for the order's type (already true in `zrexpress-push.ts:117`); add a test pinning it, and refuse push when the type is unavailable for the wilaya.
- Gate green, EN/AR parity, no hardcoded colors, live RLS suite passes.

## Real code found (plan drift)
- `wilaya_fees(workspace_id, wilaya_code, home_fee, stopdesk_fee, stop_shipping)` exists (00002; readable by all roles, admin writes). Grid UI + `saveWilayaFees` + paste box in `settings/fees-section.tsx`, `settings/actions.ts:277`; ZR sync also upserts it (`actions.ts:242`).
- No commune table exists; `orders.commune` is free text. No stop-desk availability column.
- CSV: 58 regions "N-Name"; first row of a region has `Rate_or_extra=rate|extra` and `Custom_rates="توصيل للمنزل:X|توصيل للمكتب:Y"`; following rows are communes (col City). 54 rate, 4 `extra` (Illizi 33, Tindouf 37, Bordj Badji Mokhtar 50, Djanet 56) = no price. Variants: 48 home+office, 3 office-first order, 2 home-only (54 In Guezzam 1600, 57 El Meghaier 950), 1 (8 Béchar) with the home label twice (1350|720). File has a BOM, Area/Cost columns empty.
- Code and name come from the region prefix; code must exist in `wilayas` (1–58, D26).
