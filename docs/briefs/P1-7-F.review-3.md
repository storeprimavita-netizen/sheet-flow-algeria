## Findings (ranked)

1. **MEDIUM: a colon typo silently promotes the stop-desk price to home** (`src/lib/delivery-prices.ts:128,135`). Confirmed by reading the code.
   - Input `توصيل للمنزل:1350:720` (a `:` typed instead of `|`) parses as `home: 720, priced: true` with no warning.
   - Cause: `lastIndexOf(":")` makes the label `توصيل للمنزل:1350`, and `labelKind` still matches it as home.
   - This breaks D27/D62: the wrong home price ships with no warning.
   - Fix: split on the first `:`, and warn `malformed_row` when the label still contains `:` or digits. Add a test.

2. **MEDIUM: screenshot evidence is missing, and one file is mislabeled** (`docs/design/audit/P1-7-F/`).
   - `settings-light-en-1280.png` is dark theme and shows the Settings Overview / Workspace card, not the Delivery fees grid. Nothing shows the refused-0 grid case.
   - There is no shot of the CSV preview with a commune-only change (names list and new toast).
   - `swap-refused-light-ar-390.png` shows the client "choose a wilaya" message, not the server stopped/unpriced reason that the brief item is about. There is no dark version.
   - That same shot shows the Next dev overlay "1 Issue". Nobody has checked it. It could be an uncaught error from the swap flow.
   - Fix: capture the fees grid (refused 0), the CSV commune-only preview, and the swap refused (server reason) and success screens, in both themes and AR+EN. Replace the mislabeled file. Reproduce the refused swap with the console open and fix the overlay issue.

3. **LOW: tiny or huge fees pass the parser, then the whole apply fails** (`delivery-prices.ts:153`).
   - `home:0.001` rounds to 0.00 in numeric(12,2), so the `> 0` CHECK fails and the admin sees a raw constraint error.
   - `99999999999999999999` passes the parser and then overflows.
   - Fix: allow at most 2 decimals, require a value >= 1 and below a sane cap, and warn otherwise.

4. **LOW: an explicit desk label loses to an inferred one** (review-2 #5). `home:720|home:500|desk:400` gives desk 500; the explicit 400 only gets a warning.
