# P1-1 KPI contract (brief)
risk: high · surface: none · lane: stats  (migration 00031, money, admin-only RPC; qa-reviewer + live RLS suite)

**Goal:** one SQL source `kpi_lines` for every rate and money line the dashboard needs (D4, D34, D45); pages and `pricing.ts` only format.

**Done when**
- `orders.excluded_reason` exists (admin-set, null = eligible); duplicates (`is_duplicate_suspect`) count as excluded without a backfill.
- `kpi_lines(order_ids, from, to, product, filtered)` returns, per metric, `{num, den, value, matured}` for: confirmation (decided and of-received), delivery (resolved), return, plus counts received / confirmed / on_road / delivered / returned / in_flight.
- Stages carry D34: `on_road` = confirmed orders in bureau_deposited, in_transit, out_for_delivery, stop_desk_waiting, delayed, returning, exchange (same set as `order_stock_target`); linked swap originals excluded.
- Money (admin only, null for agents): ad_spend_dzd, `usd_rate` + `usd_rate_date` (latest USD row via `current_fx_rate` logic, plus its date), ad_spend_usd = dzd / rate, cost_per_delivered and cpa_delivered in DZD and USD (null when no delivered, no rate, or filtered non-product scope), roas, net_profit, waterfall parts (revenue, cogs, delivery+returns, ads, expenses+fixed).
- `product_stock_v`: product_id, in_stock, reserved, on_road, delivered, sellable (= in_stock - reserved, floor 0), low (sellable <= low_stock_threshold). Built on `product_stock_stages` (00030); admin-only like it.
- Dashboard numbers equal the contract (no second formula); tests pass; gate green.

**Files**
- `supabase/migrations/00031_kpi_contract.sql` (next after 00030): add column + partial index (workspace_id, placed_at) where excluded_reason is null; check constraint (duplicate|test|fake|other). Create `kpi_lines` (security invoker, stable, `is_admin()` guard for money keys; rate keys also for agents, no money) REUSING `pnl_lines` output via call, not copying it. Create `product_stock_v` (security_invoker, revoke anon). Reroute `dashboard_stats` kpis/per_product/per_wilaya to call the shared eligibility/resolved expressions (one SQL helper `kpi_order_flags` or CTE). Checklist: workspace RLS inherited from orders; no new table so no trigger; `docs/DB.md` entry; regen `database.types.ts` (never hand-edit).
- `src/lib/pricing.ts`: `pnlMetrics` keeps margin, aov, breakeven only; rates read from `kpi_lines`. Update `pricing.test.ts`.
- `src/app/app/dashboard/page.tsx`, `finance/overview/page.tsx`, `products/[id]/page.tsx`: swap rate reads to the contract output (no UI redesign; that is P1-2).
- `src/lib/rls.test.ts`: new describe block.
- `docs/DB.md`.

**Definitions (from docs/council/B-kpi.md, decided here per D40)**
- Eligible = not excluded and not duplicate. Cohort = `placed_at::date` Africa/Algiers.
- Confirmation = confirmed / decided (non wait_for_confirmation); `of_received` secondary.
- Delivery = delivered / (delivered + returned + cancelled-after-pickup); in_flight shown beside. `exchange`/swap excluded from both.
- matured = den >= 10 and no unresolved order older than 7 days share > 20% (constants in the function, noted in DB.md).
- Money by USD rule D45: always latest USD rate, not the per-row `fx_rate`; DZD stays the stored truth.

**Steps (each commit+push)**
1. Migration: column, index, constraint. 2. `kpi_lines` + helper. 3. `product_stock_v`. 4. Reroute `dashboard_stats`/`product_stats`/`wilaya_stats` (keep output keys). 5. Regen types, TS consumers, `pricing.ts`. 6. Tests, DB.md, gate.

**Tests**
- `kpi: rates ignore excluded and duplicate orders`; `kpi: delivery rate uses resolved denominator, in_flight reported`; `kpi: on_road matches product_stock_stages.on_road`; `kpi: swap original counted once`; `kpi: ad spend usd = dzd / latest usd rate, null when no rate`; `kpi: cost per delivered null when filtered by wilaya`; `kpi: agent gets rates, no money keys`; `product_stock_v: agent sees no rows`; `dashboard_stats rates equal kpi_lines` (parity); pricing.test updates.

**Edge cases / assumptions**
- `exchange` and `swap` appear in enums only via later migrations; use text casts if needed.
- Existing `stage_counts.shipped` excludes only wait_for_deposit/cancelled; contract replaces it with on_road.
- Old-rule orders: 00029 reconciled stock; no data backfill here.
- Ad spend has no campaign link; product-level is the finest grain. Collected-by-ZR and paid-out stages are NOT here (ZR-4, MONEY-1): contract returns null for them.
- No new DECISIONS row needed. Remote `db push` stays owner-only.
