## Goal / done when
- `products.stock` = pieces in the warehouse. Reconcile target for an order (every INSERT/UPDATE, no per-event branches):
  `-quantity` if delivery_status in (bureau_deposited,in_transit,out_for_delivery,stop_desk_waiting,delayed,returning,exchange,delivered), else 0
  (wait_for_deposit, returned, cancelled, swap = 0). Confirmation is not part of the target (parcel stage decides). current = sum(delta) of this order's rows for the order reasons + legacy `delivered`/`returned`; insert one movement of `target - current`.
- Product shows in stock / reserved / on road / delivered, all derived: reserved = sum(qty) confirmed + wait_for_deposit; on road = sum(qty) in the on-road set; delivered = sum(qty) delivered. View `product_stock_stages` (security_invoker, admin-only via underlying RLS), no stored counters.
- Returned adds back; swapped holds nothing (original goes to 0, replacement B carries it on road under its own status).
- D35: stock_movements add-only: UPDATE/DELETE refused for everyone incl. service role; correction = new `correction` row.
- D30: a movement or an order product from another workspace is refused.
- `swap_order` safe on double submit: second call returns the existing B, creates nothing.
- Gate green, live RLS suite 3x, types regen (`--local`), DB.md, i18n key parity.
