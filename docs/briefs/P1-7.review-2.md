## Findings (ranked)

1. **MEDIUM — failed grid save silently reverts `stop_shipping`.** `src/app/(app)/app/settings/fees-section.tsx:139`
   - The `stop_*` Switch is uncontrolled (`defaultChecked`). React 19 resets the form after every form action, including one that returns `{error}`, and the Radix Switch goes back to its default on reset.
   - Failure: turn wilaya 16 stop-shipping on and, in the same save, re-enable another wilaya with no fee. The save returns `errNeedFee` and the stop switch flips back off. The admin then adds the fee and saves successfully, but the stop flag is lost and new orders to 16 are no longer blocked.
   - Fix: make `stop_*` controlled, like `priced`/`desk` (lines 90, 104, 123).
   - The same reset also wipes customer name, phone and address in `orders/order-form.tsx:132-170` after `createOrder` returns `{error}`, and the swap-card fields after a swap error. Fix: control those inputs, or return the submitted values and re-seed them.
2. **MEDIUM — a file that only fixes commune spellings cannot be applied.** `src/lib/delivery-prices.ts:227` (`cur.communes !== w.communes.length`) together with the Apply button's `changedCount === 0` disabled state in `fees-csv-dialog.tsx`.
   - Failure: a file that renames communes but keeps the same count and fees shows 0 changed. Apply stays disabled and the "changed only" filter hides the row.
   - Fix: return the stored commune names (or a hash of them) in the stored snapshot and compare the sets.
3. **MEDIUM — every wilaya that was never given a fee is "priced" at 0 DZD.** `supabase/migrations/00052_delivery_prices.sql:7-9` (`priced default true`, no backfill). The `wilaya_fees` rows created in 00007 hold 0 fees.
   - Failure: after a clean reset, 46 of the 58 wilayas show Priced on with an empty fee (`grid-en-dark-390.png`). The order form and webhook then charge 0 DZD delivery for them, and the preview shows "0 DA → 1 400 DA". This breaks the brief's "no 0 DZD for no price" rule.
   - Fix: in 00053 or a new migration, `update wilaya_fees set priced=false where home_fee=0 and stopdesk_fee=0`, and flag any priced row with a 0 fee in the grid.
   - Note for the owner: on the remote database this turns shipping off for any wilaya still at 0 until a CSV is imported. Call this out in PROGRESS.
