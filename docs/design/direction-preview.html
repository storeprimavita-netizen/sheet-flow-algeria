MNW COD ERP · Phase 11 design direction

Two directions, both themes — pick one before we write tokens

The same dashboard vignette rendered four ways. Both directions are dark-first, high-contrast and quiet, built for an ops team that lives in this tool all day. They differ only in surface hue and the single accent color — the status-pill palette is identical in both, because status is the primary information in a COD dashboard.

Direction A — Slate & Emerald: cool slate surfaces, restrained emerald accent. Evolves today's look, lowest risk. Direction B — Graphite & Azure: near-neutral graphite, confident azure accent. Neutral ground makes statuses pop hardest.
Colors are the exact OKLCH tokens in docs/design/DESIGN_SYSTEM.md. Type is shown in the system UI font; production uses IBM Plex Sans (already loaded) with tabular numerals on every figure. Decorative glass/gradient panels from the current build are intentionally gone here.
